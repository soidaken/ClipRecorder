# ClipRecorder

[![build](https://github.com/soidaken/ClipRecorder/actions/workflows/build.yml/badge.svg)](https://github.com/soidaken/ClipRecorder/actions/workflows/build.yml)

[简体中文](README.md) · [English](README.en.md) · **日本語**

Windows ネイティブのスクリーンショット・画面録画・範囲翻訳ツールです。常駐型で、Go で書かれ、UI は [MyGo](https://github.com/egoist/mygo) が直接描画します（GPU によるネイティブ UI）。WebView・HTML・JavaScript を使わず、FFmpeg にも依存しません。

## できること

- **スクリーンショット**：範囲を選択してクリップボードにコピー。
- **画面録画**：選択範囲を H.264 / MP4 で録画。システム音声とマイクの同時録音、アスペクト比、フレームレート、画質、ハードウェアエンコーダーの選択に対応。ビットレート行の右側に「硬编 / 软编」バッジで、現在の設定で実際に使われるエンコーダーを示します。
- **範囲翻訳**：英語の範囲をドラッグして離すと、その場で中国語に置き換わります。カード・ボタン・背景・アイコンはそのまま残し、英語だけを消して、元の色・サイズ・太さ・揃え方で中国語を同じ位置に配置し、段落は元の幅で組み直します。翻訳中は選択範囲をスキャン光が流れ、結果が出たらマウスを押している間は原文を表示します。オーバーレイには 2px の枠線が付き、`Esc`（他のウィンドウにフォーカスがあっても有効）または右クリックで閉じます。

## 基本操作

| ショートカット | 動作 |
| --- | --- |
| `Ctrl+I` | 範囲を選択 → 緑の「确认」ボタンまたは `Enter` でコピー |
| `Ctrl+R` | 範囲を選択 → 設定 → 「Start recording」または `Enter` で録画開始。選択後に内側からドラッグすると範囲全体を移動できます |
| `Ctrl+T` | 英語の範囲を選択 → 離すと認識・翻訳してその場に表示 |
| `Ctrl+Shift+T` / フローティングバーの「停止」 | 録画を停止して保存 |
| `Esc` / 右クリック | 選択をキャンセル |

トレイメニューからも同じ操作ができ、スタートアップ起動も切り替えられます。

## スクリーンショットの注釈

範囲を選ぶとツールバーに 3 つの注釈ツールが現れます。既定ではどれも未選択で、もう一度押すと解除されます。

- **ペン**：選択範囲内を自由に描画（5px の赤）。
- **ぼかし**：選択範囲内で矩形をドラッグし、離すとその領域をぼかします（強さ 75）。
- **番号**：選択範囲内をクリックすると 1、2、3… の赤い円（半径 12px、白の太字）が付きます。
- **範囲マーク**：選択範囲内に赤い角丸の破線枠（6px）をドラッグで描けます。複数可。

「确认」で出力する画像は macOS のウィンドウキャプチャ風になります。連続曲率の角丸となめらかなアンチエイリアス、細い輪郭線、下方向へのやわらかい影を付けます。周囲の余白は完全に透明（PNG は透過を保つ）で、影の大きさは画像サイズに合わせて変わるため、色の板を敷かずにどの背景へ貼っても浮いた見た目になります。ツールバーの四角いアイコンでオフにすると元の 1:1 画像になります。

「确认」を押すと PNG を `%USERPROFILE%\Pictures\ClipRecorder\` にも保存します。ツールバーの「复制路径」は既定でオンで、クリップボードには画像（PNG + DIB）・ファイル・絶対パスのテキストが一緒に入ります。チャットやオフィスアプリは画像かファイルを、テキストしか受け付けない入力欄（ターミナルなど）はパスを受け取ります。WPS/Excel のセルのようにテキストがあるとパスを貼り付けるアプリでは、オフにすると画像だけになります。クリップボードの内容は確定直後にすべてシステムへ渡すため、その後 ClipRecorder が忙しくても終了していても貼り付けできます。

注釈はコピーされる画像に含まれます。左下のヒントのとおり `Esc` で取り消せます。範囲を選んだ後に外側をクリックしても選び直しにはならず、変更したいときは `Esc` で終了してから選び直します。範囲の内側からドラッグすると描き直しになり、注釈は消えます。

ツールバーの「低 / 中 / 高」はコピーする解像度です。低は長辺 1280px に縮小、中（既定）と高は画面の物理ピクセルを 1:1 で出力します。クリップボードはロスレス PNG のみなので、中／高が最良の画質です。

録画中はフローティングバーが録画範囲に重ならない画面の角（右下→右上→左下→左上）に置かれるため、キャプチャ保護は不要で、リモートデスクトップや画面共有でも見えます。録画範囲が画面全体を覆う場合のみ保護されます。

録画ファイルの保存先：`%USERPROFILE%\Videos\ClipRecorder\`。録画が終わって保存されると、その絶対パスが自動でクリップボードにコピーされます。

翻訳を初めて使うときに DeepSeek API キーの入力が必要です。入力したキーは Windows DPAPI で暗号化してローカルに保存されます（`%APPDATA%\ClipRecorder\deepseek-key.dat`）。選択したスクリーンショットは JPEG で DeepSeek に送信され、認識と翻訳に使われます。

選択のたびにダウンロードフォルダへ 2 枚保存されます。`translate_<時刻>.jpg` はモデルに送った元の切り抜き、`translate_<時刻>_zh.png` は描画後の中国語結果です。

翻訳は二つを同時に進めます。Windows 標準の OCR がローカルで各単語の正確な位置を求め、DeepSeek のビジョンモデルが段落ごとに読み取って翻訳します。両者を原文で突き合わせ、文字サイズ・ベースライン・文字色・背景色・揃え方はスクリーンショットの画素から測るため、訳文は元の位置にぴったり収まります。数字・日付・IP など翻訳不要な部分は元の画素のままです。OCR の言語がない場合や位置を合わせられなかった場合は、白地に訳文を順に並べて表示します。送信前に画像はモデルが処理する解像度（約 170 万画素）まで縮小され、英語のまま返った段落は小さなテキストのみのリクエストで一度だけ再翻訳します。インストール／上書きインストール時は実行中の ClipRecorder を自動で終了し、録画中なら保存を先に完了させます。

## 技術スタック

| 部分 | 実装 |
| --- | --- |
| 言語 / UI | Go + MyGo v0.5.5：ネイティブウィンドウ、GPU ガラスパネル、トレイ、グローバルホットキー、クリップボード |
| 画面キャプチャ | Win32 GDI `BitBlt` を Go から直接呼び出し（録画のフレームバッファを共有） |
| 映像 | Windows Media Foundation、H.264 / MP4。ハードウェアエンコーダー（NVENC など）を自動検出し、使えなければソフトウェアにフォールバック |
| 音声 | [go-wca](https://github.com/moutend/go-wca) 経由の WASAPI。システム音声とマイクをミックスして AAC 48kHz |
| 文字認識 | DeepSeek のビジョンモデルが段落ごとに認識し、Windows 標準 OCR がローカルで単語の位置を提供 |
| 翻訳 | DeepSeek Chat API |

## ダウンロード

[Releases](https://github.com/soidaken/ClipRecorder/releases) から `ClipRecorder-Setup.exe` を取得してください。`%LOCALAPPDATA%\Programs\ClipRecorder` にインストールされ、既定でスタートアップに登録されます（トレイから解除可能）。

インストール不要版が必要な場合は `build.ps1` で `dist/ClipRecorder.exe` をビルドして実行してください。

Windows 10 / 11（64 ビット）が必要です。

## ソースからビルド

Go 1.27+ が必要です。インストーラーを作る場合は Inno Setup 6 のコンパイラーも必要です（`ISCC` 環境変数でパスを指定可）。

```powershell
go run .
.\build.ps1            # dist/ClipRecorder.exe
.\build-installer.ps1  # dist/ClipRecorder-Setup.exe
```

`build.ps1` はこのプロジェクトの ClipRecorder が起動中なら先に終了してから、`dist/ClipRecorder.exe` を上書きします。GitHub Actions が push のたびに exe とインストーラーをビルドし、`v*` タグでは Release を公開します。ドキュメントのみの変更（`*.md`、`LICENSE` など）ではビルドを実行しません。

## 制限

- マウスカーソルは録画されません。録画中の音声デバイス切り替えはできません。
- 選択範囲に対する注釈、ウィンドウ吸着、端のドラッグ調整はありません。
- DRM 保護されたコンテンツは黒画面になる場合があります。
- 複雑な段組み、装飾フォント、回転したテキストは、翻訳後のレイアウトが元と一致する保証はありません。
